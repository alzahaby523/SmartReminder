# تذكير ذكي (Smart Reminder) — تطبيق أندرويد

تطبيق مهمته التذكير فقط، لكن بطريقة ذكية تعتمد على حالة الهاتف لحظة التنبيه.

## سلوك التنبيه

| حالة الهاتف | وضع «صوتي» | وضع «صوري فقط» |
|---|---|---|
| مفتوح (الشاشة تعمل وغير مقفل) | إشعار منبثق مباشر | إشعار منبثق مباشر |
| مقفل / الشاشة مطفأة | جرس مرتين ← ثم نطق التذكير ← مع الإشعار | إشعار + اهتزاز بدون صوت |

مثال على النطق: «تنبيه. عندك موعد بعد نصف ساعة مع شركة الأمل.»
أو: «تنبيه. عندك عمل بعد ساعة: مراجعة التقرير.»

الوقت المنطوق يُحسب لحظة التنبيه فعلياً (نصف ساعة، ساعة ونصف، ساعتين، 15 دقيقة، دقيقتين ...).
في الإشعار زران: **تم** و **غفوة 10 د**.

## التشغيل

1. افتح مجلد المشروع في **Android Studio** (Ladybug أو أحدث) وانتظر مزامنة Gradle.
2. وصّل هاتفاً أو شغّل محاكياً (Android 8.0 / API 26 فأعلى) واضغط Run.
3. اسمح بإشعارات التطبيق عند السؤال (Android 13+).
4. اضغط **🔔 تجربة** في أعلى الشاشة: يصلك تنبيه بعد 10 ثوانٍ؛ أقفل الشاشة لتسمع الجرس ثم الصوت.

## ملاحظات مهمة

- **الصوت العربي**: النطق يعتمد على محرك النص-إلى-كلام في الهاتف. إن لم يُسمع الكلام، ثبّت بيانات العربية:
  الإعدادات ← النظام ← اللغة ← إخراج النص إلى كلام ← محرك Google ← تثبيت بيانات الصوت ← العربية.
  وإن لم يتوفر صوت عربي يكتفي التطبيق بالجرس مرتين والإشعار.
- **مستوى الصوت**: الجرس والنطق يخرجان من قناة «المنبّه»، فتأكد أن صوت المنبّه في الهاتف غير مكتوم.
- **توفير الطاقة**: في بعض الأجهزة (Xiaomi, Huawei, Oppo, Samsung) أضف التطبيق إلى
  «غير مقيّد» في إعدادات البطارية كي لا يؤخر النظام التنبيهات.
- التذكيرات تُحفظ على الهاتف وتُعاد جدولتها تلقائياً بعد إعادة التشغيل.

## هيكل الكود

```
app/src/main/java/com/smartreminder/app/
├── MainActivity.kt      الواجهة (Jetpack Compose): القائمة + شاشة الإضافة/التعديل
├── Model.kt             Reminder + التخزين (SharedPreferences/JSON)
├── Receivers.kt         الجدولة (AlarmManager) + مستقبلات التنبيه والأزرار والإقلاع
├── ReminderService.kt   منطق التنبيه الذكي (فتح/قفل، جرس مرتين، النطق)
├── Notifications.kt     قناة الإشعارات والإشعار المنبثق
├── Util.kt              صياغة الوقت بالعربية ونصوص النطق
└── Theme.kt             الثيم وفرض اتجاه RTL
app/src/main/res/raw/bell.wav   صوت الجرس
```
